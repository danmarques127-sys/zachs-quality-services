# Security Policy

## Supported Versions

This is a production website project. Only the currently deployed production version is supported for security updates.

## Reporting a Vulnerability

If you discover a security vulnerability related to the Zach’s Quality Services website,
its codebase, or its infrastructure, please report it responsibly.

### How to Report
- Email: zachsqualityservices@gmail.com
- Subject: Security Vulnerability Report

If the email above is not available, use:
- Email: marquesdangelo@hotmail.com

### What to Include
Please provide as much detail as possible:
- A clear description of the vulnerability
- Affected URLs, routes, or files (if known)
- Any relevant logs, screenshots, or request/response samples
- Your assessment of impact (e.g., data exposure, account takeover, defacement)

### Response Timeline
We aim to acknowledge reports within **3 business days** and provide a remediation plan or status update as soon as possible.

## Responsible Disclosure

Please do not publicly disclose security issues until they have been reviewed and addressed.
Avoid exploiting the vulnerability beyond what is necessary to demonstrate the issue.

Thank you for helping keep this project and its users safe.
